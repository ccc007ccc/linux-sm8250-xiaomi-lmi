## OV13B10 纠正说明

从 POCO F2 Pro / Redmi K30 Pro 相关实机硬件信息看，后摄 13MP 超广角位更应按 **OmniVision OV13B10** 处理，而不是 Samsung S5K3L6。OV13B/OV13B10 是 13MP、1.12µm、1/3.06″ 的 MIPI RAW 传感器，传感器本身支持 PDAF，但在 Redmi K30 Pro / POCO F2 Pro 的 13MP 超广角模组中通常按固定焦距超广角使用，不应直接因为 sensor 支持 PDAF 就假定整机该镜头有 AF 马达。

## 关键字段说明（对内核适配友好）

### 主摄像头（Sony IMX686）
- 对焦支持：PDAF + Touch Focus。
- 稳定方式：仅 EIS。
- ISP 通道：启用完整主摄路径与对焦控制节点。
- 视频能力：8K@30fps，4K@60fps，1080p 多帧率。
- 元数据: AF 状态、曝光、白平衡、畸变校正。

### 超广角镜头（OmniVision OV13B10）
- 定位：13MP 超广角后摄，官方规格对应 123° FOV、f/2.4。
- 传感器能力：OV13B/OV13B10 为 13MP、4208×3120、1.12µm、1/3.06″，支持 10-bit RAW、MIPI 输出、裁切/窗口/镜像翻转等控制。
- 对焦：传感器本身支持 PDAF 像素，但该机超广角模组应按固定焦距处理；除非你在板级 DTS / actuator / EEPROM 中确认存在独立 VCM，否则不要给它挂 AF actuator。
- 内核表现：需要 sensor driver、CCI/I2C 地址、电源时序、MIPI lane/clock、mode table、OTP/校准读取；通常不需要 AF VCM 节点。
- 元数据：焦距、FOV、畸变系数、固定焦距状态。超广角的畸变矫正对 HAL/算法层很重要。

### 宏距 / 近距镜头（Samsung S5K5E9）
- 对焦：AF 自动对焦。
- 对焦范围：约 3 cm – 10 cm。
- 内核需支持 AF 控制路径与传感器对焦驱动。

### 深度/景深传感器
- 不参与成像输出，仅用于深度估计。
- Camera HAL/算法层接入深度信息即可。

### 前置摄像头（Samsung S5K3T2 / 需以实机 probe 为准）
- 对焦机制：固定焦距（无 AF / VCM）。
- 公开资料存在 S5K3T2 与 S5K3T1 两种写法；DeviceInfoHW 实机探测与英文机型资料更偏向 S5K3T2，中文机型资料有 S5K3T1 记录。内核适配时应以 boot log / probe name / camera EEPROM 或 vendor DTS 为最终准据。
- 软件算法可提供虚拟对焦/脸部识别优化。

## 内核/驱动适配建议

| 适配点 | 是否必须 | 说明 |
|--------|-----------|------|
| 对焦控制节点（PDAF/AF） | 必须（后置主摄、宏距） | 创建正确对焦 ioctl / V4L2 控制项 |
| 固定焦距通道 | 必须（超广角、前置） | 无对焦驱动，但需正确输出 FPS & metadata |
| 畸变系数 & 焦距元数据 | 必须 | 用于 HAL/算法层矫正图像与 UI |
| EIS 加速数据 | 强烈建议 | 驱动适配 gyro + 视频 pipeline |
| 视频输出多帧率模式 | 强烈建议 | 8K/4K/HFR 等不同模式支持 |

## 术语解释

- **PDAF**：Phase Detection AF，快速自动对焦。
- **AF**：Auto Focus，一般 AF 驱动控制。
- **FF**：Fixed Focus，固定焦距。
- **EIS**：Electronic Image Stabilization。
- **元数据**：对焦状态、曝光、镜头参数、畸变参数等，用于 HAL 与算法。
